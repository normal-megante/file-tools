# ファイルツール箱

画像・PDF・動画・音声の「ちょっとした作業」をまとめた、自分用のツール集です。
無料・回数無制限で、PC でもスマホでも使えます。

- **画像 → PDF**：JPEG / PNG / WebP などを1つの PDF に（用紙・余白・向き・画質・白黒を選べる）
- **画像の変換・圧縮**：JPEG / PNG / WebP の変換、画質、ファイルサイズの上限、縮小、回転・反転・切り抜き
- **QR コード作成**：URL・文章、Wi-Fi、連絡先。PNG / SVG で保存
- **QR コード読み取り**：スクショや写真の中の QR コードを読む（1枚に何個あっても全部）。PC は Ctrl+V で貼り付け、スマホは「共有」でアプリに送る、カメラでも読める。URL は行き先を大きく表示（偽サイト対策）、Wi-Fi はパスワードをコピー、連絡先・予定はファイルで保存
- **スキャン補正**：書類やノートの写真の四隅を自動で見つけてまっすぐにし、影を消して文字や手書きの線をくっきり。スマホのカメラから直接撮れる。PDF か画像で保存
- **PDF のページ整理**：結合・分割・抜き出し、ページの並べ替え・回転・削除。画像も1ページとして入れられる。画質は落ちない
- **PDF → 画像**：PDF のページを JPEG / PNG / WebP の画像に。きれいさ（100〜300 dpi）を選べて、全部か選んだページだけ。1枚ずつか ZIP で保存
- **PDF の圧縮**：「ふつう」は文字・しおり・リンク・フォームはそのままで、中の写真だけを表示される大きさに合わせて縮める。「強力」はページを丸ごと画像にする。強さは3段階。パスワードつき PDF も使える
- **PDF に書き込み**：文字・日付・チェック（✓○×）・白塗り・手書き・ハンコやサインを書き込む。置いたものは動かす・大きさを変える・消す・元に戻すができる。元の文字・しおり・リンクはそのままで、上に書き足して保存（白塗りは見た目を隠すだけで、下の文字はデータに残ります）
  - ハンコ・サイン：名字から赤い丸の印鑑を作る、指やマウスでサインを書く、本物のハンコやサインの写真から白い紙を透明にして取り込む。作ったものはこの端末に保存して何度も使える（見た目だけのもので、電子署名ではありません）
- **動画・音声の変換**：動画を MP4 / WebM に、音声を MP3 / M4A / WAV / FLAC / OGG に。動画を軽くする（大きさ・画質・「◯MB 以下」）、動画から音声を取り出す、音声どうしの変換。ファイルごとに使う所だけ切り取る・回転もできる

ファイルはすべて端末の中で処理します（サーバーには送りません）。
Edge や Chrome の「アプリとしてインストール」「ホーム画面に追加」で、アプリのように使えます。ネットにつながっていなくても開けます。

## 開発

HTML / CSS / JavaScript だけで作っています（ビルド作業なし）。

- PC で確認：このフォルダで `python dev-server.py` → http://localhost:8140
- 仕様と作業メモ：[CLAUDE.md](CLAUDE.md)

## 使わせてもらっている部品

- [pdf.js](https://mozilla.github.io/pdf.js/)（Mozilla）… PDF のページの表示と画像化。Apache License 2.0。`vendor/pdfjs/` に同梱（ライセンス文も同じ場所）
- [Mediabunny](https://mediabunny.dev/)（Vanilagy and contributors）… 動画・音声の読み書きと変換。Mozilla Public License 2.0。`vendor/mediabunny/` に同梱（ライセンス文も同じ場所。中身は書き換えていません）
  - MP3 を作る部分に [LAME](https://lame.sourceforge.io/)（GNU LGPL）を使っています（Mediabunny の MP3 部品の中に入っているもの）
  - FLAC を作る部分に [libFLAC](https://xiph.org/flac/)（Xiph.Org、BSD ライセンス）を使っています（Mediabunny の FLAC 部品の中に入っているもの）
